# Discord Age Restriction Setup

This project is adults only. If you use a Discord community link, configure the server or relevant channels so minors cannot access adult content.

## Recommended Setup

1. Keep the invite link public only in adults-only project pages.
2. Add a clear rule: adults only, minors prohibited.
3. Configure relevant channels as age-restricted in Discord channel settings.
4. Put downloads, support, screenshots, logs and device discussions inside age-restricted channels.
5. Keep a separate public welcome/rules channel with no adult content, if needed.
6. Ask users to confirm they are adults before showing them download/support channels.

## Suggested Welcome Text

Adults only. This community discusses OSR6 / OSR-compatible realtime TCode output software and related hardware. Minors are prohibited. By continuing, you confirm that you are legally allowed to view and discuss this type of content in your jurisdiction.
