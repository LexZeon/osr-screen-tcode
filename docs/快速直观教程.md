# 直接输出脚本教程


**成年人使用提示：本项目面向成年人使用，未成年禁止入内。**

这个教程给只想尽快用起来的人。目标是少调参数，先稳定输出。

## 第一次打开

1. 解压中文版或英文版免安装包。
2. 优先双击 `OSR6-Realtime-Screen.exe`，或双击 `Start.cmd`。
3. 先点“恢复所有默认设置”。出现确认弹窗后确认。
4. 连接 OSR6。能看到设备状态变化后，再继续。
5. 点“测量模式”，用滑块遥控 L0 上下移动。
6. 保存一个舒服、安全的上限，再保存一个舒服、安全的下限。

上下限会保存在本地。下次打开如果已经能正常输出脚本，就不用再点“恢复所有默认设置”。

## 实时输出

1. 打开你要读取的画面。
2. 点“开始实时输出”。
3. 弹窗里选择 Screen。
4. 选择 L0 或六轴。
5. 框选屏幕区域。尽量框住主要运动区域，别把无关弹幕、列表、边框都框进去。
6. 分析模式先用“混合分析（推荐）”。
7. 先用默认五档预设的第 3 档。
8. 开始后看曲线和数值，确认不是长时间卡在最上或最下。

## 出问题时

- 动作太大：降低 L0 总行程倍率，或重新测量上下限。
- 动作太抖：提高平滑/降抖，降低敏感度。
- 长时间卡极限：换更干净的框选区域，或降低行程倍率。
- 方向反了：打开 L0 反向。
- 设备异常：先急停。
