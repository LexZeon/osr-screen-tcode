# 快速预览

1. 双击根目录 Start.cmd。
2. 保持 Log only，不连接硬件。
3. 默认打开“输出监视”。选择区域/视频与分析模式后开始；点击“显示预览”查看经过所有倍率及输出限制后的 3D 指令模拟。切换到“分析预览”查看同帧画面。
4. 选择 RTM Pose 2D 时需要本地模型；默认混合分析 v2 支持单／六轴，可开关 RTM 2D 旋转辅助；混合分析 1 保留原有 L0 核心（推荐-平面大幅动作）。
5. 对比原始/处理后画面；默认处理最长边为 640。
