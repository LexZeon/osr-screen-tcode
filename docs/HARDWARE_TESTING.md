# Maintainer Hardware Use Report / 维护者实机使用反馈

## English

### Reported use — 2026-11-12

**Application release: 2.1.1.** This record summarizes the maintainer's first-hand feedback received on **2026-11-12**. The maintainer reports that the current version has practical value in real-device use. It is a use report, not a controlled benchmark, independent certification or a general compatibility claim.

| Reported area | Feedback |
| --- | --- |
| Connections used | USB-C connection and BLE connection. |
| Dance analysis | L0 and Six Axis output produced useful real-device results. |
| Hybrid Analysis | L0 output produced useful real-device results. |

The connections and modes above are not a complete connection-by-mode test matrix. This report does not claim that every connection was separately verified with every analysis/output mode.

### Scope and information not recorded

- Device model, firmware, detailed settings, test materials and session duration were not supplied in this report.
- The Hybrid Analysis feedback does not identify v1 or v2; it must not be attributed to either one without further information.
- No measured accuracy, latency, long-term reliability or per-axis calibration results are reported. Practical usefulness does not establish those measurements or compatibility with every device.
- This feedback does not validate real depth/contact, robot-arm joint mapping, inverse kinematics, collision detection or physical position feedback. The simulator displays final commands, not hardware feedback.

### Relationship to release validation

This feedback was received after the **2026-10-17** release checks. The [2.1.1 validation record](https://github.com/LexZeon/osr-screen-tcode/blob/v2.1.1/docs/Validation_2.1.1.md) describes those automated and isolated checks, including their stated hardware limits. This later first-hand use report is separate evidence; it does not rewrite what those earlier checks performed.

The application version remains **2.1.1**. This documentation update does not change the program, configuration, historical validation/release records, tags or published ZIPs. See the [2.1.1 feature guide](https://github.com/LexZeon/osr-screen-tcode/blob/v2.1.1/docs/FEATURES.md) for the existing controls and behavior.
