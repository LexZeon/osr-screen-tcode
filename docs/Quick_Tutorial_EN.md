# Quick Tutorial

This is the shortest path to usable output for OSR6 Realtime Screen TCode.

1. Extract the Windows package.
2. Start `OSR6-Realtime-Screen.exe`, or run `Start.cmd`.
3. On first run, restore defaults once.
4. Connect the OSR6 device.
5. Enter measurement mode, move L0 manually, and save safe upper/lower limits.
6. Click realtime output.
7. Select Screen, choose L0 or Six Axis, select the screen region, and use the recommended hybrid analysis mode.

Limits and settings are stored locally. If the app works normally next time, do not restore defaults again unless you intentionally want to reset everything.
