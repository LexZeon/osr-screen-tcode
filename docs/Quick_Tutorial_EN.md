# Quick Tutorial

> **SR6/OSR6 Realtime Screen TCode High Hardware Compatibility v2.0.0-test.3:** BETA prerelease with Windows portable and source ZIPs. Extract the entire Windows folder and run `Start.cmd`; Python is not required for the portable build. Models and optional GPU runtimes are downloaded in-app, not bundled. Device measurement/sweep instructions concern native TCode hardware; new experimental hardware and custom bindings are described in [Device Compatibility](Device_Compatibility_2.0.md). For optional GPU installation and current changes, see the [main README](../README.md).

This is the shortest path to usable output for SR6/OSR6 Realtime Screen TCode High Hardware Compatibility.

1. Extract the Windows package.
2. Start `SR6-OSR6-Realtime-Screen-TCode-High-Hardware-Compatibility.exe`, or run `Start.cmd`.
3. On first run, restore defaults once.
4. Connect the OSR6 device.
5. Enter measurement mode, move L0 manually, and save safe upper/lower limits.
6. Click realtime output.
7. Select Screen, choose L0 or Six Axis, select the screen region, and use the recommended hybrid analysis mode.

Limits and settings are stored locally. If the app works normally next time, do not restore defaults again unless you intentionally want to reset everything.
