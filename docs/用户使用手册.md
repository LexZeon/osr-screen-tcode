# OSR6 Realtime Screen TCode 用户使用手册

当前版本：`1.0.1`。每次新版改了什么，可以看软件文件夹里的 `版本日志.txt`。

> **成年人使用提示：本软件面向成年人使用，未成年禁止入内。**
>
> **六轴模式警告：六轴只建议在光线好、主体清晰、框选区域干净的画面里使用。** 画面太暗、遮挡多、主体不清楚、裁切太近或无关运动太多时，请先用 `L0 Only` 或 `Log only` 预览。
>
> 第一次正式使用前，建议先用“测量模式”保存适合自己的安全上限/下限。上下限会保存到本地电脑。下次如果能正常输出脚本，就不用再点“恢复所有默认设置”，除非你想全部重置。

## 概述

这是一个本地运行的 OSR/SR6/OSR6 实时控制工具。它可以读取屏幕区域、视频文件或系统声音，把画面/声音变化转换成 TCode，通过 USB 串口或 BLE UART 发送给 OSR6 等 TCode 兼容设备。

软件会把主要设置保存在本机用户目录，下次打开会继续使用上次调好的数值，比如上下限、倍率、五档预设、六轴灵敏度、串口/BLE、声音参数等。

软件默认推荐使用 `混合分析（推荐）` 分析模式。这个模式采用混合 ROI 光流思路：先锁定主要运动区域，再用稠密光流分析运动方向和强度。它比单纯运动中心更跟手，也比纯方向判断更不容易把每次动作都打满。

推荐第一次使用流程：

1. 连接设备前，先把输出方式设为 `Log only`，确认画面分析和输出值稳定。
2. 框选视频里最主要的运动区域。
3. 使用第 `3` 档预设开始。
4. 先用 `L0 Only`，确认上下方向和幅度。
5. 再连接 OSR6，先点 `连接并回中`，然后点 `中等测试`。
6. 感觉稳定后，再逐步扩大每轴上下限或提高五档预设。
7. 需要观察动作时点击 `显示预览`，先看 3D 模拟器里的输出是否符合预期。

## 直接运行

在文件夹里双击：

```text
OSR6-Realtime-Screen.exe
```

也可以双击：

```text
Start.cmd
```

启动时会先弹出两个窗口：

1. 成年人警告：本软件面向成年人使用，未成年禁止入内。
2. 语言选择：选择 `中文` 后进入中文界面，选择 `English` 后进入英文界面。

## 连接设备

### USB 串口

1. 把 OSR6 控制器插到电脑。
2. 软件左侧 `连接设备` 区域里，输出选择 `Serial COM`。
3. 点 `刷新`。
4. 选择设备串口，通常显示为 `COMx`。
5. 波特率通常用 `115200`。
6. 点 `连接并回中`。
7. 点 `查询设备轴` 可以读取固件开放的通道；正常 OSR6 应至少包含 `L0/L1/L2/R0/R1/R2`。

如果连接失败，可以试：

- 重新插拔 USB。
- 换一根数据线。
- 确认没有别的软件占用同一个 COM 口。
- 尝试其它波特率，如 `9600`、`57600`、`250000`。

### 蓝牙

蓝牙有两种常见情况：

- Windows 已经把蓝牙设备映射成 COM 口：直接在 `Serial COM` 里选对应 COM 口。
- BLE UART：输出选择 `BLE UART`，点扫描，确认写入 UUID。

如果配对时需要密码，常见值是 `1234` 或 `123`。

## 实时监控区

主界面右侧顶部是实时监控区。

它会显示：

- 当前 `L0` 输出值。
- 当前是插入方向、拔出方向，还是中段。
- 当前 L0 下限/上限。
- 活动量或声音强度。
- 六轴条形监控。
- 最近约 12 秒实际输出的脚本曲线。
- 最新发送的 TCode 命令。

### 五档一键预设

实时监控顶部有 `1 2 3 4 5` 五档按钮。

- `1`：更慢、更柔、更小幅。
- `2`：偏柔和。
- `3`：默认推荐档。
- `4`：更快、更积极。
- `5`：更刺激，速度和幅度都更大。

五档预设只调整体验参数：速度、平滑、死区、活动阈值、视觉行程、L0 总行程倍率和六轴总行程倍率。它不会重写六轴独立上下限。

### 六轴辅助轴

`六轴敏感度 1..10` 会切到 `Six Axis`，并调整 `L1/L2/R0/R1/R2` 跟随 `L0` 主节奏的强度。`1` 最稳最慢，`5` 是新版默认，`6..10` 更灵敏、更刺激。新版会绕过 L0 用的大死区，避免其它轴因为每帧变化太小而完全不动。

如果六轴抖动明显，把 `六轴降抖` 往右拉，或直接点 `一键稳六轴`。这个滑块只会降低非 L0 轴敏感度并增加平滑，不会影响 L0。若其它轴太弱，可以先把对应轴上下限放宽一点，或把 `总强度`、单轴强度略微上调。

鼠标悬浮在界面里的按钮、标签和参数名上，会出现一句简短提示，说明它是干什么的。

`展开更多设置` 里放的是不常改的输入来源、声音、框选和算法参数。日常使用时可以收起，只保留连接、开始/停止、五档预设、限位、倍率和曲线。

点击 `开始实时输出` 时，软件会自动切到屏幕实时读取，并先弹出确认窗口。用户可以在这里重新框选屏幕区域，选择 `L0 Only` 或 `Six Axis`，切换分析模式，开启或关闭 `Pose 倾向 L0 / Pose 倾向六轴`，并调整两个 Pose 权重。确认已经调好上下限后，再点 `确认开始` 才会输出脚本。

`恢复所有默认设置` 位于 `开始实时输出` 上方。点击后会弹出确认警告；确认后会重置屏幕区域、输入来源、输出方式、串口/BLE 信息、每轴上下限、L0/六轴总行程倍率、五档预设、六轴辅助参数、声音参数和高级参数，并立刻覆盖本机保存的配置。正在实时输出时不能恢复默认，需要先停止。

`显示预览` 位于 `开始实时输出` 下方。点击后会打开 OSR6 3D 预览，再点一次会变成 `取消预览` 并停止同步。这个预览不是分析器原始结果，而是软件实际发出的 TCode：已经经过每轴上下限、L0/六轴总行程倍率、限速、平滑、死区和六轴敏感度处理，所以它和设备端收到的脚本一致。

### L0 防抽搐

高级参数里的 `启用 L0 防抽搐` 默认开启，`L0 防抖` 越高，越会压住画面噪声造成的短促上下反转。画面本身比较抖、输出像在原地抽动时，可以点 `一键稳态 L0`，或把 `L0 防抖` 调到 `0.75..0.9`。这项不会改变 `L0` 的机械下限/上限，真实的大幅上下运动仍会继续输出。

## 框选屏幕区域

点左侧 `屏幕区域` 里的 `框选区域`。

进入全屏半透明选择层后：

- 蓝色虚线框表示当前已保存区域。
- 鼠标移动时有十字辅助线。
- 拖拽时会实时显示宽、高、X、Y。
- 松开鼠标后不会立刻应用，会出现确认面板。

快捷键：

- `Enter`：使用此区域。
- `R`：重新选择。
- `Esc`：取消。

建议只框选主要运动区域，避免把字幕、播放器进度条、边缘闪烁和其它无关运动框进去。

## 输入来源

### Screen

实时读取屏幕区域，适合边播放边控制设备。

### Video File

读取本地视频文件，既可以实时播放分析，也可以点 `分析视频并保存脚本` 生成 `.funscript`。

### Audio Only

只监听声音，不读取画面。适合 PMV、节奏类视频、音乐驱动玩法。

声音设备建议：

- `System Output`：监听电脑正在播放的声音。
- `Default Input`：默认麦克风或输入设备。

声音分析模式：

- `Audio Level`：音量越大位置越高。
- `Dynamic Accent`：跟随声音动态强度，动作更连续。
- `Beat Pulse`：检测节奏上升沿，适合鼓点明显的音频。

## 输出模式

### L0 Only

只输出上下轴 `L0`。这是最稳定、最适合初次调试的模式。

### Six Axis

同时输出六轴：

| 轴 | 含义 |
| --- | --- |
| `L0` | 上下 stroke |
| `L1` | 前后 surge |
| `L2` | 左右 sway |
| `R0` | twist |
| `R1` | roll |
| `R2` | pitch |

六轴分析是启发式估计，不等同于人工多轴脚本。建议先把 `L0 Only` 调稳定，再切到 `Six Axis`。

### 六轴辅助调节

`六轴辅助调节（不影响 L0）` 用来控制 `L1/L2/R0/R1/R2` 的体感参与程度。新版默认让其它轴更低敏、更平滑，只做主节奏旁边的辅助动作。

- `总强度`：整体放大或缩小除 L0 外的五个轴。
- 每个轴旁边的数字：该轴自己的强度，`0` 等于基本关闭，`100` 是默认，`200` 是两倍。
- `反`：把该轴方向反过来。
- `六轴敏感度 1..10`：十档非 L0 辅助轴灵敏度，数字越小越稳，`5` 是新版默认，`6..10` 更灵敏、更刺激。
- `一键稳六轴`：一键降低辅助轴敏感度并提高降抖。

这些控件不会改变 L0。当前 L0 已经稳定时，可以只调这里和每轴上下限。

建议调法：

1. 先切到 `Six Axis`。
2. 把 `L1/L2/R0/R1/R2` 的上下限收窄，比如 `4000..6000`。
3. `总强度` 先用 `100`。
4. 逐个把某个轴强度提高或降低。
5. 如果某个轴感觉方向反了，只勾它旁边的 `反`。
6. 调稳以后，再慢慢扩大该轴上下限。

## 行程和幅度控制

### 六轴独立上下限

每个轴都有自己的下限和上限。它们是硬边界，软件输出不会越过这些值。

第一次连接真实设备时建议：

```text
L0: 2500 .. 7500
其它轴: 4000 .. 6000 或更窄
```

确认方向和体感后，再慢慢扩大。

### 测量模式

`测量模式` 在六轴独立上下限上方。

使用方式：

1. 先停止实时输出。
2. 连接设备，并确认能 `急停回中`。
3. 在 `轴` 里选择要测的轴，默认是 `L0`。
4. 慢慢拖动 `位置` 滑块，机器会跟随移动。
5. 当前的位置适合作为最低安全位置时，点 `保存为下限`。
6. 当前的位置适合作为最高安全位置时，点 `保存为上限`。
7. 点 `当前轴回中` 可以把当前测量轴发回 `5000`。

如果不想滑动时实时发送，可以取消勾选 `滑动即发送`，然后拖好位置后手动点 `发送当前位置`。

测量模式发送的是原始 TCode 位置值 `0..9999`。第一次使用建议从中间 `5000` 附近开始，慢慢扩大，不要一上来直接推到极限。

### L0 总行程倍率 / 六轴总行程倍率

这两个滑块位于六轴独立上下限上方，最高到 `3.00x`。

它们不会改变每个轴的下限/上限，只会在输出前围绕中点缩小或放大行程。

滑条是分段手感：`0..1` 占最长，`1..1.5` 更短，`1.5..1.75` 更短，`1.75..3` 集中在最右侧。这样常用的低倍率更好精调，高倍率只作为刺激增强区。

- `L0 总行程倍率`：只影响 L0 上下主轴。
- `六轴总行程倍率`：只影响 L1/L2/R0/R1/R2 辅助轴。
- 往左：动作更小、更克制。
- 中间 `1.0`：默认。
- 往右：动作更大、更满。

即使往右放大，也不会超过每个轴自己的上下限。

### 视觉行程

`视觉行程` 在高级参数里。

它控制画面动作被放大成设备行程的程度。

- 默认约 `0.72`。
- 往左：更贴近画面真实幅度，小动作更小。
- 往右：更容易接近满幅。

如果角色画面没有真的插入到底，但设备却总是从最上到最下，可以优先降低 `视觉行程` 或 `L0 总行程倍率`。

## 分析模式

点击 `开始实时输出` 后，确认弹窗里也可以临时切换分析模式、框选屏幕区域，并调节 `Pose 倾向 L0 / Pose 倾向六轴`。Pose 权重越大，越偏向完整人物舞蹈、扭腰、横摆的理解：L0 越不容易把左右摆动误判成上下，六轴辅助越会体现身体角度和横摆。

开启任意 Pose 倾向后，读取画面的右边会显示一个黑底近似骨架预览：白色骨架线、蓝色关节。这个骨架是根据实时分析和输出轴估计出来的，用于观察趋势，不是慢速的人体关键点模型。

### 混合分析（推荐）

默认推荐模式。它使用 ROI 光流思路，适合大多数屏幕实时分析和视频分析。

特点：

- 更跟手。
- 对小幅动作有层次。
- 支持视觉行程缩放。
- 比纯光流更适合成人视频里的局部运动。

### Stroke Phase（内测用）

只判断主要垂直方向。向下认为是插入，向上认为是拔出。

优点是稳，缺点是容易把动作简化成两端来回。

### Motion Center（内测用）

追踪画面变化区域的中心点。适合主体位置特别清楚、背景干净的画面。

### Optical Flow（内测用）

根据全局光流跟随运动。画面整体抖动时可能不稳。

### Hybrid Motion（内测用）

混合运动中心和光流。适合尝试，但不作为默认。

### Activity Pulse（内测用）

根据画面变化强度生成节奏。适合位置难判断但变化很强的画面。

## 高级参数

### FPS

屏幕读取帧率。更高更跟手，也更占 CPU。

推荐：

```text
30 .. 60
```

### 间隔 ms

TCode 命令间隔。越小越快。

推荐：

```text
20 .. 33
```

### 每帧限速

限制每次输出最大变化量，避免突然跳变。

### 平滑曲线

让动作更顺，但太高会有延迟。

### 极端位自动复位 / 端点保护

`极端位自动复位` 会在 L0 长时间贴近上限或下限时，把输出慢慢松回中段，避免一直顶住不动。`端点保护` 只作用于 L0，会给上下两端留一点缓冲；如果想要更大行程，可以把 `端点留白 %` 调小，但建议不要直接关掉保护。

### 死区滤波

忽略微小抖动。太高会漏掉小动作，太低可能抖。

### 活动门控

画面变化低于阈值时保持或回中。可以减少静止画面的误动作。

### 响应曲线

- `Linear`：最自然。
- `Soft`：柔和。
- `Sharp`：中段更敏感，更容易靠近两端。
- `Ease In`：中段更克制。

当前推荐 `混合分析（推荐）` 搭配 `Linear`。

### 空闲

- `Hold`：没有足够活动时保持当前位置。
- `Center`：没有足够活动时回到中点。

### 启动渐入

开始实时输出时从中点逐步进入目标动作，避免突然启动。

### 反向

反转 `L0` 上下方向。如果感觉插入/拔出方向反了，可以打开。

## 视频分析并保存脚本

1. 输入来源选择 `Video File`。
2. 点 `选择`，选择视频。
3. 输出模式选择 `L0 Only` 或 `Six Axis`。
4. 分析模式推荐 `混合分析（推荐）`。
5. 点 `分析视频并保存脚本`。

六轴模式会输出多个 companion funscript 文件：

- `.funscript`
- `.surge.funscript`
- `.sway.funscript`
- `.twist.funscript`
- `.roll.funscript`
- `.pitch.funscript`

## 录制实时动作

点 `开始录制` 后，实时输出过程中的动作会被记录。

点 `保存脚本` 可以保存为 funscript。

## 推荐调参方案

### 太抖

按顺序试：

1. 框选区域缩小，只保留主要运动。
2. 降到第 `2` 档或第 `1` 档。
3. 增加 `平滑`。
4. 增加 `死区`。
5. 增加 `活动阈值`。

### 动作太小

按顺序试：

1. 升到第 `4` 档。
2. 提高 `L0 总行程倍率`。
3. 提高 `视觉行程`。
4. 扩大 `L0` 上下限。

### 每次都撞上下限

按顺序试：

1. 降低 `视觉行程`。
2. 降低 `L0 总行程倍率`。
3. 使用第 `2` 或第 `3` 档。
4. 响应曲线用 `Linear`，不要用 `Sharp`。

### 延迟太明显

按顺序试：

1. 降低 `平滑`。
2. 降低 `间隔 ms`。
3. 提高 FPS。
4. 使用 USB 串口，少用蓝牙。

## 安全建议

- 第一次实机使用先把上下限调窄。
- 先用 `连接并回中`，再做小幅测试。
- 不舒服或异常时立即点 `急停回中`。
- `上下全幅测试` 会检查真实 L0 上下限，使用前确认设备安装安全。
- 六轴模式先把非 L0 轴范围调小。
