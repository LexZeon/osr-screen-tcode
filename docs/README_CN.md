# OSR6 Realtime Screen TCode v1.1.2


**成年人使用提示：本项目面向成年人使用，未成年禁止入内。**

这是 OSR 六轴屏幕读取实时输出脚本工具。它可以读取屏幕框选区域、视频文件或声音节奏，并实时输出 L0 或六轴 TCode，用于 OSR6 / OSR 兼容设备。

## 重要警告：六轴模式使用条件

**六轴模式只建议在光线好、主体清晰、框选区域干净的画面里使用。** 如果画面太暗、遮挡很多、主体不清楚、裁切太近，或者无关运动太多，请先用 L0 模式或 Log only 预览。画面输入不好时，六轴更容易抖动、漂移或误判。

第一次正式使用前，建议先用“测量模式”保存适合你自己设备和体感的上限/下限。上下限会保存到本地电脑。下次打开如果能正常输出脚本，就不用再点“恢复所有默认设置”，除非你就是想全部重置。

提示：鼠标光标悬浮在按钮、滑块、参数名上，会出现小字解释，告诉你这个功能是干嘛的。
## 直接运行

1. 解压压缩包。
2. 优先双击 OSR6-Realtime-Screen.exe，或双击 Start.cmd。
3. 第一次使用，建议先点“恢复所有默认设置”。
4. 连接 OSR6 设备。
5. 用“测量模式”保存安全上限和下限。
6. 点“开始实时输出”，建议先 L0；六轴只在画面清晰稳定时使用。

上下限和调参会保存到本地。下次打开如果已经能正常输出脚本，就不用再点“恢复所有默认设置”。

## 没有设备先预览

输出选择 Log only，点击“显示预览”，再点“开始实时输出”并框选一个正在播放的画面区域。这样可以先看曲线、画面预览和输出趋势，不会控制硬件。

## 功能

- OSR6 / OSR 兼容设备实时 TCode 输出。
- L0 模式和六轴模式。
- USB 串口和 BLE UART 连接。
- 屏幕实时读取、视频生成脚本、声音监听模式。
- 混合分析（推荐-非舞蹈）、RTM Pose 3D 骨架标注、曲线预览、3D 预览。
- 本地保存设置、测量模式、急停、上下限、倍率、平滑、限速、六轴敏感度。
