# 专业教程


**成年人使用提示：本项目面向成年人使用，未成年禁止入内。**

这份教程适合想细调画面分析、六轴体验和发布参数的人。

## 工作流

1. 连接设备并确认输出通道。
2. 测量 L0 上下限，把机械安全边界保存到本地。
3. 框选屏幕区域，尽量只保留真正和节奏相关的区域。
4. 选择分析模式。
5. 用曲线预览观察输出是否有极端卡死、噪声抖动或延迟过大。
6. 再逐步打开六轴、Pose、声音监听或其它辅助功能。

## 分析模式

- 混合分析（推荐）：综合局部画面运动、方向相位、活动量、回中逻辑和滤波，适合大多数视频和屏幕实时场景。
- 光流/相位/运动中心等模式：更适合排查问题或测试特殊素材，不建议新用户一开始就使用。
- Pose：更偏完整人物舞蹈或身体姿态趋势，权重越高越像在跟随整体人物动作。对局部画面或裁切很近的画面，权重过高可能不如混合分析稳定。
- 声音监听：适合画面信息少但节奏明显的 PMV 或音乐节奏场景。

## 上下限和倍率

上下限是硬边界，程序输出不会越过它们。L0 总行程倍率和六轴总行程倍率是软倍率：在上下限内部放大或缩小动作。

建议：
- 先用安全上下限。
- 再调倍率。
- 不要靠极端上下限来追求刺激，先保证急停和回中都可靠。

## 六轴调试

六轴由 L0 主节奏派生，并叠加画面横向、旋转、姿态、活动量等趋势。辅助轴不应该比 L0 更敏感。感觉抖时优先降低六轴敏感度，提高一键降抖，而不是直接拉大上限。

## 低延迟建议

- 框选区域越小，分析越快。
- 优先用混合分析推荐模式。
- Pose 只在完整人物画面里开启。
- 曲线预览能保留，但如果电脑吃紧，可以关闭 3D 预览。
