# Contributing


**Adults only: this project is intended for adults. Minors are prohibited.**

Thanks for considering a contribution.

This project is a realtime OSR6 / OSR-compatible screen-reading TCode output tool. Contributions are welcome, especially in these areas:

- safer device output behavior
- lower-latency analysis
- more stable six-axis tuning
- better UI text and translations
- docs, screenshots and onboarding
- device compatibility reports

## Before Opening A Pull Request

1. Open an issue or clearly explain what the PR changes.
2. Do not include private videos, adult media, personal logs, hardware serial numbers, local paths, tokens, or account data.
3. Keep hardware-safety behavior conservative by default.
4. If you add an analysis mode, include a short explanation of when it should be used.
5. If you borrow code, make sure its license is compatible and update `THIRD_PARTY_NOTICES.md`.

## Vibe Coding

This project openly acknowledges AI-assisted development. That is fine. What matters is that changes are tested, explained, and safe for real hardware use.
