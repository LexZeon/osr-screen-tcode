OSR6 Realtime Screen TCode 版本日志

版本号规则：
- 每次发给别人使用前，都要更新这里。
- 小修复递增最后一位，例如 0.9.1。
- 功能明显变化递增中间位，例如 0.10.0。
- 当前版本：1.1.0。

1.1.0 - 2026-09-03
- 正式合并 1.1.0 测试线：保留原基础分析和 L0 稳定输出逻辑，新增 RTM Pose 3D 骨架标注测试能力和一键模型下载入口。
- 新增“压缩延迟”滑块，可在准确度和低延迟之间调节；RTM Pose 3D 也会受该设置影响。
- 优化 Windows 高 DPI 框选和实时捕捉坐标一致性，减少选右侧窗口却抓到错误区域的问题。
- 优化设备连接稳定性：USB 串口和 BLE 连接改为后台试连，失败或超时时界面保持可操作。
- 整理普通用户界面：BLE 设置仅在 BLE 模式显示，测量模式/轴上下限、六轴辅助调节和 RTM Pose 3D 设置支持折叠。
- 六轴辅助调节标注为仅混合分析使用；RTM Pose 3D 输出不接入这组混合分析微调。
- 新增 L0 总行程倍率、六轴总行程倍率以及 L1/L2/R0/R1/R2 单轴行程倍率，所有输出仍受上下限、限速和安全保护约束。
- 更新源码启动脚本、依赖、README、中文/英文教程、用户手册和版本日志。

1.1.0-test.9 - 2026-09-03

1.1.0-test.8 - 2026-09-03

1.1.0-test.7 - 2026-09-03
- Pose v2 底层逻辑改为先推测简化人物骨架，再由肩线、躯干中线、腰点、左右髋点和膝点推算骨盆核心带。
- 软件截取预览画面会显示 Pose v2 推测骨架：青色为骨架，绿色为实际读取的骨盆核心带，紫色为拟合出的髋部平行四边形。
- 优化人物横向分析：逐行优先保留靠近躯干中线的连续前景段，降低手、头发、尾饰和画面边缘把骨架拉歪的概率。
- 骨盆核心带下移到更接近“腰以下、腿以上”的区域，减少误把胸部/上衣宽度当作骨盆的问题。
- 骨盆出画、不稳定或骨架跳变时，Pose v2 继续本帧放弃并回到基础分析。

1.1.0-test.6 - 2026-09-03
- 继续优化 Pose v2 骨盆核心带：不再只按固定高度取框，而是根据人物整体轮廓、横向宽度和中下身结构推算更窄的核心区域。
- Pose v2 平行四边形优先使用核心带里的运动点拟合；运动点不足时才使用固定核心带低置信度回退，减少把大腿整体当骨盆的问题。
- 新增骨盆可能出画判断：核心带贴近边缘、下半身被画面底部裁掉或侧边裁切严重时，本帧放弃 V2，自动回到基础分析。

1.0.0 - 2026-09-02
- 第一个准备公开发布的正式版：功能已覆盖 OSR 六轴屏幕读取、实时 TCode 输出、设备连接、曲线预览、教程和 GitHub Release 包。
- 推荐分析模式改名为“混合分析（推荐）”，界面、默认配置、视频分析命令行、README、用户使用手册和 AI 接手提示词同步改名；旧配置会自动迁移，不改变分析功能。
- 主界面简化：低频功能下移到“展开更多设置”，常用连接、开始/停止、急停、预设、测量、上下限、倍率和曲线留在主视图。
- 六轴敏感度从 1..5 扩展到 1..10，默认 5 档；1..5 保留原手感，6..10 更灵敏。
- 新增/强化 L0 总行程倍率和六轴总行程倍率，最高 3.00x，滑条为非线性分段，低倍率更容易细调。
- 开始实时输出会自动切到 Screen，并在启动前弹窗确认输出模式、屏幕区域、分析模式和 Pose 权重。
- 预览显示改为固定尺寸画布，实时刷新图片不会再让窗口重新计算大小。
- 修复开始实时输出后字体变小的问题：禁止 mss 截图库在运行中修改 Windows 进程 DPI 感知，避免 Tkinter 字体缩放突然变化。
- 保留窗口自由拖动和缩放：不再持续锁定窗口尺寸。
- 额外准备 GitHub 开源发布包：包含公开源码、中文版/英文版下载说明、快速直观教程、专业教程、Vibe coding 声明和开源鸣谢；不包含本机路径、临时文件、个人测试脚本和 AI 接手提示词。
- 简易教程改为中英文 13 步直达流程，所有教程截图改为真实软件界面标注版，并在每张截图中加入编号框；网页/视频区域已遮挡，避免第三方网页、成人画面或个人信息出现在 GitHub 页面。
- 发布文档增加醒目六轴警告：六轴模式只建议在光线好、主体清晰、框选干净时使用；简易教程强调第一次正式使用前先用测量模式保存适合自己的上下限，且上下限会保存到本地。
- 发布文档加入新的 Discord 邀请链接，并明确提醒服务器/频道应设置年龄限制；保留邮箱 aivnailedeng@gmail.com 作为侵权、许可证修正、建议和合作反馈渠道。
- 发布文档增加成年人提示：本项目面向成年人使用，未成年禁止入内。
