SR6/OSR6 Realtime Screen TCode High Hardware Compatibility 版本日志

版本号规则：
- 每次发给别人使用前，都要更新这里。
- 小修复递增最后一位，例如 0.9.1。
- 功能明显变化递增中间位，例如 0.10.0。
- 当前版本：2.0.0-test.3。

2.0.0-test.3 - 2026-09-05
- 所有下拉列表按完整文字和实际字体自动加宽，不改变收起时侧栏布局；超出屏幕宽度时可水平滚动。
- 开始实时输出弹窗支持滚动和调整大小，底部确认/取消按钮保持可见；GPU 状态文字按可用宽度换行。
- CUDA 检测区分 CPU 版 ONNX Runtime、cuDNN 缺失和实际推理失败，增加已安装 CUDA/cuDNN 目录查找及重新检测按钮。
- 新增 ONNX Runtime + DirectML，可用于支持 DirectX 12 的 AMD/NVIDIA/Intel 显卡，无需 CUDA；主界面和开始弹窗共享后端选择，本地保存，恢复默认回到 CUDA 且 GPU 关闭。
- RTM 2D/3D 仅替换推理后端，复用 rtmlib 的预处理和骨架解码；DirectML 顺序执行、关闭内存模式优化，GPU 加载或运行失败时回退 CPU。
- 一键安装显示真实下载百分比、已下载/总大小和组件名称，以及解析、准备、解压安装、推理验证阶段；未知大小不伪造百分比。
- 下载通过 SHA-256 校验后离线安装，CUDA/DirectML 分开保存。安装或切换运行库按提示重启；失败不覆盖原环境。
- 通过隔离目录实测 DirectML 下载、安装和 GPU 推理，未修改现有运行库；AMD 真机与所有 RTM 模型的速度仍需用户测试。
- 同步中英文说明，鸣谢志愿测试与建议提供者“电话机”，英文保留中文名字与引号。
- 按授权生成 BETA 免安装 exe/Windows ZIP 和纯源码 ZIP，发布到 2.0.0-High-Hardware-Compatibility-BETA 分支，不合并 main 或替换正式版。
- 免安装版新增隐藏子进程的 GPU 检测与 pip 安装入口，支持没有 Python 的电脑在软件内安装运行库；修复冻结环境的 pip 资源读取，打包优先读取当前 clone 的源码。
- 下载遇到截断或校验失败时最多重试三次，始终验证 SHA-256，不发布损坏文件；界面注明 CUDA 运行库较大、DirectML 较小，不承诺准确率差异。
- Windows 与源码包均排除模型、可选 CUDA/cuDNN/NVIDIA/DirectML 运行库、本地设置、缓存和开发中间文件；保留 CPU 推理必需依赖。
- 基础分析、L0/六轴算法及安全输出逻辑不因本次打包和界面说明修改而改变。
