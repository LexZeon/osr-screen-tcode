OSR6 Realtime Screen TCode 版本日志

版本号规则：
- 每次发给别人使用前，都要更新这里。
- 小修复递增最后一位，例如 0.9.1。
- 功能明显变化递增中间位，例如 0.10.0。
- 当前版本：1.0.2。

1.0.2 - 2026-09-03
- 新增“压缩延迟”滑块，范围 -5 到 5，默认 0；更多设置和开始实时输出确认弹窗都可以调整。
- 界面标注 `-5 最准确 / 0 默认 / 5 延迟最低`，并同步英文界面显示。
- 默认 0 保持原始画面和现有算法路径不变；调到 1..5 时才降低分析分辨率，以换取更低延迟。

1.0.1 - 2026-09-03
- 新增可提交到 Git 的双击启动脚本 `Start.cmd` 和源码启动脚本 `Start-Source.cmd`：Windows 用户 clone 仓库后可直接双击运行源码版。
- `Start-Source.cmd` 会自动创建本地 `.venv`、安装/修复运行依赖，并从 `src` 启动主程序；`.venv` 和缓存仍不会进入 Git。
- README 增加中英文“从源码运行 / Run From Source”说明。

1.0.0 - 2026-09-02
- 第一个准备公开发布的正式版：功能已覆盖 OSR 六轴屏幕读取、实时 TCode 输出、设备连接、曲线预览、教程和 GitHub Release 包。
- 推荐分析模式改名为“混合分析（推荐）”，界面、默认配置、视频分析命令行、README、用户使用手册和 AI 接手提示词同步改名；旧配置会自动迁移，不改变分析功能。
- 主界面简化：低频功能下移到“展开更多设置”，常用连接、开始/停止、急停、预设、测量、上下限、倍率和曲线留在主视图。
- 六轴敏感度从 1..5 扩展到 1..10，默认 5 档；1..5 保留原手感，6..10 更灵敏。
- 新增/强化 L0 总行程倍率和六轴总行程倍率，最高 3.00x，滑条为非线性分段，低倍率更容易细调。
- 开始实时输出会自动切到 Screen，并在启动前弹窗确认输出模式、屏幕区域、分析模式和 Pose 权重。
- 预览显示改为固定尺寸画布，实时刷新图片不会再让窗口重新计算大小。
- 修复开始实时输出后字体变小的问题：禁止 mss 截图库在运行中修改 Windows 进程 DPI 感知，避免 Tkinter 字体缩放突然变化。
- 保留窗口自由拖动和缩放：不再持续锁定窗口尺寸。
- 额外准备 GitHub 开源发布包：包含公开源码、中文版/英文版下载说明、快速直观教程、专业教程、Vibe coding 声明和开源鸣谢；不包含本机路径、临时文件、个人测试脚本和 AI 接手提示词。
- 简易教程改为中英文 13 步直达流程，所有教程截图改为真实软件界面标注版，并在每张截图中加入编号框；网页/视频区域已遮挡，避免第三方网页、成人画面或个人信息出现在 GitHub 页面。
- 发布文档增加醒目六轴警告：六轴模式只建议在光线好、主体清晰、框选干净时使用；简易教程强调第一次正式使用前先用测量模式保存适合自己的上下限，且上下限会保存到本地。
- 发布文档加入新的 Discord 邀请链接，并明确提醒服务器/频道应设置年龄限制；保留邮箱 aivnailedeng@gmail.com 作为侵权、许可证修正、建议和合作反馈渠道。
- 发布文档增加成年人提示：本项目面向成年人使用，未成年禁止入内。
- 软件名称和 Windows 主程序文件名统一为英文：OSR6 Realtime Screen TCode / OSR6-Realtime-Screen.exe，降低中文文件名在部分电脑上无法启动或被误识别的概率。
- 修复公开包双击启动只出现黑色窗口的问题：Windows 版改为纯图形界面启动，并让成年人确认窗口强制置顶显示。
- 启动流程改为两步：先显示成年人警告（英文大字、中文小字），确认后再选择界面语言（中文 / English）；同一个软件不再按中英文包锁定语言。
- 软件界面、开始实时输出弹窗、运行状态、错误提示、屏幕框选层、脚本曲线文字和鼠标悬浮解释会按选择的语言显示；分析模式英文显示名会自动映射回原内部算法名，不影响已有算法。
- 新增英文完整用户手册 `User_Manual_EN.md`，并把快速教程截图升级为多图分步标注版；Windows 包和源码包都包含真实英文界面截图。
- 验证：源码编译通过；混合分析新旧名称兼容；开始实时输出后预览刷新不缩窗口；手动缩放后预览刷新不抢回窗口；免安装版 exe 启动不闪退。
